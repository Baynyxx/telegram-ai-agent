# AI TELEGRAM AGENT

Бот, который позволяет пользователю управлять своим компьютером с помощью нейросети прямо через Telegram.

## Что умеет этот бот

* **Запоминать информацию** — бот может сохранять важные данные о пользователе и использовать их в дальнейшем, не занимая контекстное окно нейросети лишними токенами.

* **Открывать программы** из списка, который задаёт пользователь.

* **Включать и выключать растяг**. XD

* **Общаться по-человечески** — бот старается вести диалог в человеческой манере, а не просто отвечать сухими сообщениями.

* **Узнавать состояние и название комплектующих ПК**.

* **Узнавать, какое окно сейчас находится в фокусе**.

* **Форматировать текст** — бот поддерживает форматирование сообщений, чтобы ответы выглядели аккуратно и удобно для чтения.

* **Сохранять историю переписки**, благодаря чему можно обращаться к предыдущим сообщениям и сохранять контекст общения.

* **Поддерживать Reply** — бот понимает, на какое сообщение пользователь отвечает, и может учитывать его содержимое при формировании ответа.

## Установка

Чтобы начать пользоваться ботом, создайте `.env` файлы в каждой папке, где они необходимы, и укажите в них нужные значения.

После этого запустите бота.

## Структура проекта

Весь код рассортирован по отдельным файлам, чтобы его было удобнее читать, редактировать и дополнять.

Удачи в использовании! ❤

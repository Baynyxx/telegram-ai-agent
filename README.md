# telegram-ai-agent
Бот, позволяющий пользователю управлять своим компьютером с помощью нейросети.

Чтобы начать пользоваться, создайте .env файлы в каждой папке и укажите в них нужные значения.

Что умеет этот бот:


Запоминать информацию, в обход контекстного окна (Жрёт токены).

Открывать программы из списка пользователя.

Включать и выключать растяг. XD

Общаться с человеческой манерой.


Весь код рассортирован по файлам, для удобного редактирования, удачи в использовании. ❤
